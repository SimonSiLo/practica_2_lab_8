Este proyecto implementa una funcion llamada calculateTip, el cual es usado para calcular propinas en un restaurante 
basandose en el consumo del cliente y el porcentaje de propina deseado.
La practica se enfoca en el uso de ramas en Git para gestionar el desarrollo de algunas caracteristicas del codigo.

Algunos ejemplos de codigos usados estan en el documento de word, pero de los mas esenciales fueron:
-git branch "nombre de la rama" (este para crear una nueva rama)
-git checkout -b (para cambiar entre ramas y usarlas)
-git branch (para mostrar las ramas)

Algunos conflictos que hubieron al momento de crear todas las ramas y el codigo de javascript como tal, fueron:
-Dificultad para integrar cambios de ramas
-Confusion al trabajar con ramas locales y remotas (al momento de hacer el repositorio remoto)
